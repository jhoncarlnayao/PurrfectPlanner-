## About

PurrfectPlanner is a ticket-styled task planner built for Filipino students. It combines daily to-dos, class schedules, streak tracking, and focus sessions into a single board that lives entirely in your browser. There is no sign-up and no server involved, and all data stays on the user's device.

Every task is treated like a physical ticket that can be added, edited, dragged, reordered, and cleared off the board, complete with a stamp animation on completion.

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Edge, or Safari)

### Installation

```bash
git clone https://github.com/<your-username>/purrfectplanner.git
cd purrfectplanner
```

### Running locally

Since PurrfectPlanner is fully client-side, it can be opened directly or served with any static file server:

```bash
# Option 1: open directly
open index.html

# Option 2: serve locally
npx serve .
```

Then open the app in your browser.

## Project Structure

```
purrfectplanner/
```

## Data & Privacy

All planner data is stored locally in the browser using `localStorage`. No data is transmitted to any server, and no account or sign-up is required to use the app.
